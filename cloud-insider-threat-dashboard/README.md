# Insider Threat Lab

A local Streamlit frontend for the CERT r4.2 insider-threat project. The original notebook is included for the full sampler comparison and research analyses; the dashboard reuses its feature engineering, sequence, training, and HGB scoring modules for interactive local runs.

## What it does

- Streams CERT event CSVs and builds behavioral features in 2-day user windows.
- Trains the notebook's HistGradientBoosting detector using user-level train/validation/test splits.
- Tunes alert thresholds on validation users and reports fresh held-out test metrics.
- Saves the model, run settings, results, and a ranked test-user CSV.
- Scores another CERT-format dataset with a saved model and exports a ranked user CSV.

The default UI trains one production split with the selected sampler. It does not automatically run the notebook's longer Layer 1 sampler comparison, 7-fold out-of-fold analysis, neural-network ablations, or temporal analysis. Use the original notebook for those experiments. The notebook's written example metrics are marked stale; use metrics generated by a fresh run.

## Data layout

Obtain the same CERT release and answer key used for your project. Keep them locally; do not put them in the shared project ZIP or repository.

The folder containing event files should include the available CERT CSVs, commonly:

```text
logon.csv
device.csv
email.csv
file.csv
http.csv
```

The dashboard searches recursively below the event-folder path. The labels path should point to `insiders.csv` (or a compatible `answers.csv`). For an `insiders.csv` containing multiple releases, the release field defaults to `r4.2` and the app filters to that release.

## Windows setup

1. Install Python 3.12 and unzip the project folder.
2. Double-click `setup_windows.bat` once. It creates a project-local virtual environment and installs dependencies.
3. Double-click `run_app.bat`. The dashboard opens in your browser on this computer.
4. In the sidebar, set the event folder, labels file, and output folder, then choose **Build features and train model**.

You can also run it from PowerShell:

```powershell
py -3.12 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
streamlit run dashboard.py
```

Choose a smaller CSV chunk size in the sidebar if memory is limited. The first feature pass can take a while on full CERT data; its cache is saved under the selected output folder and reused when the dataset path and feature settings match.

## Using the notebook's saved outputs (no retraining)

If you already ran the notebook on Kaggle, download its output folder (the one containing `results.json`, `oof_user_scores_hgb.csv`, `oof_window_scores_hgb.csv`, `hgb_feature_importance.csv` and `hgb_model/hgb.pkl`) and unzip it, for example into `work/notebook_run`. In the dashboard open **Load saved results**, enter that folder and press **Load results**. You get the held-out test metrics, every user ranked by out-of-fold score with an adjustable review budget, feature importance, and a per-user risk timeline. The saved `hgb_model/hgb.pkl` also works in **Score a dataset**. You do not need `features_*.pkl` or the code folder in the zip.

## Training on Kaggle (when the dataset is too big for your computer)

The dashboard can't read files that live on Kaggle, so split the work: train on Kaggle, view locally.

1. Create a Kaggle notebook, add the CERT r4.2 dataset as an input, and upload this project folder (or add it as a dataset).
2. Run in a cell (adjust the paths to your dataset):

   ```text
   !pip install -q -r requirements.txt
   !python kaggle_run.py --data-dir /kaggle/input/<cert-dataset> --answers /kaggle/input/<cert-dataset>/answers/insiders.csv
   ```

   Options mirror the sidebar (`--sampler`, `--seed`, `--user-budget`, ...). It writes `/kaggle/working/insider_run.zip`.
3. Download `insider_run.zip` from the notebook's Output tab and unzip it, for example into `work/kaggle_run`.
4. Run the dashboard locally, open the **Load Kaggle results** tab, enter that folder and press **Load results**.

The zip holds `results.json`, `test_user_scores.csv`, `model/hgb.pkl`, `model/model_config.json` and the feature cache. The saved model can also be used in **Score a dataset** on any smaller CERT-format folder you have locally.

## Outputs

The selected output folder contains:

```text
features_w2.pkl            cached features
model/hgb.pkl              trained HGB model and scaler
model/model_config.json    settings required to score more data
results.json               run config and held-out evaluation metrics
test_user_scores.csv       ranked held-out users and evaluation labels
```

For a new dataset, open **Score a dataset**, select the saved `model/hgb.pkl`, and point to the new CERT event folder. The output folder receives `scored_users.csv`; this scoring-only run does not calculate precision or recall because it has no answer key.

## Sharing with teammates

- Send the ZIP alongside this README, or place this project folder in a private team repository.
- Each teammate installs the dependencies and points the dashboard to their own copy of the data and labels.
- The project excludes `data/`, `work/`, model pickles, and virtual environments by default.
- To reproduce your evaluation, teammates should use the same CERT release, answer key, sampler, and sidebar settings.
